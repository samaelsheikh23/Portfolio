ABOUT SAMA ELSHEIKH

Turning Data into Intelligent Machine Learning Solutions

I turn messy data into machine learning models that actually make sense.

I'm an entry-level Machine Learning Engineer with a foundation built on math, not just tools a mix that lets me clean, question, and understand data before I ever train a model. My path started with a genuine love for mathematics, patterns, and problem-solving.

I believe most machine learning problems aren't really algorithm problems they're data problems in disguise. A model can only be as good as the data behind it, which is why I spend the time others skip: understanding what the data is actually saying before I try to predict anything with it.

My approach: Every project follows the same discipline: understand the problem, clean and explore the data thoroughly (EDA), choose the right algorithm deliberately (not by default), and evaluate honestly rather than chasing a good-looking accuracy score.

This portfolio showcases 2 completed projects where I've applied that approach from data cleaning and exploratory analysis to building and evaluating machine learning models end-to-end.

I'm actively looking to bring this mindset to a startup or growing team, where I can keep learning fast, take ownership of real problems, and grow into the Machine Learning Engineer I'm working to become.
